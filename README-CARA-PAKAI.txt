CARA PAKAI (2 KLIK):
1. Buka folder "website"
2. Double-klik "index.html" → form feedback langsung bisa dipakai
3. Untuk admin: double-klik "admin.html" → langsung ada 12 contoh ulasan + % penilaian

TIDAK PERLU INSTALL APAPUN. Data tersimpan otomatis di browser.
